# Detro Tap

## How do I install these formulae?

`brew install detro/tap/<formula>`

Or `brew tap detro/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "detro/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
